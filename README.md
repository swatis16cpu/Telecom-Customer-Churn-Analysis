# Telecom Customer Churn Analysis

## 📌 Project Overview
This project analyzes customer churn in a telecom company using Python. The goal is to identify the factors that influence customer churn and provide insights that can help improve customer retention.

## 📊 Features
- Data cleaning and preprocessing
- Handling missing values
- Exploratory Data Analysis (EDA)
- Customer churn visualization
- Business insights from data
- Data-driven conclusions

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Project Structure
```
├── TCA(1).ipynb
├── README.md
└── dataset.csv (if included)
```

## 📈 Analysis Performed
- Data preprocessing
- Missing value handling
- Customer demographics analysis
- Churn distribution analysis
- Service usage analysis
- Contract type analysis
- Payment method analysis
- Monthly and total charges analysis
- Visualization using charts and graphs

## 🎯 Key Insights
- Customers with month-to-month contracts are more likely to churn.
- Higher monthly charges are associated with increased churn.
- Long-term customers tend to stay with the company.
- Service type and payment method influence customer retention.
